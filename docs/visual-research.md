## 设计决策

1. **不再把 JPG 当角色主体**：v3.0.0 的 L2 整张 `side.jpg` 已从 Client 移除；`assets` 只保留未来接口说明，公开包无图。
2. **L2 角色主题区域**：右侧限宽 `min(22vw,300px)`、`portrait-height` 默认 55vh、可关闭；由机关伞 SVG + 抽象墨影 + 红飘带 + 锁扣构成，不冒充 Live2D。
3. **机关伞**：独立 SVG，8 个伞面分区、8 根伞骨、铰链、中央轴、伞柄、金屑、红边；分区与伞骨各自 7s 开合，铰链独立微微缩放，非整把 rotate。
4. **锁链/导电**：SVG 路径 + `stroke-dasharray/dashoffset` 4.2s/6.4s 连续流动；5.2s 低频短促红白脉冲；不新增 Canvas/粒子。
5. **L3 机关锁**：保留已验收的玄朱锁 SVG，缩到 22em/0.2 透明度，避免盖住正文。
6. **遮挡策略**：场景只作为中心列内的绝对定位层（z-index:0），正文/输入为 z-index:1；所有场景元素 `pointer-events:none`；≤1200px 隐藏 L2，≤1100px 隐藏 L3，≤900px 全关；气泡隐藏 ≤1280px。
7. **动态降级**：隐藏/失焦暂停 CSS 动画与 rAF；reduced-motion 关闭开合、旋转、锁链、导电、视差、呼吸；触摸与窄屏关视差。

## 与旧版差异

- v3.0.0：L2 是一张 JPG 立绘，尺寸/透明度可调但无法避免遮挡与素材限制。
- v3.1.0：L2 改为可独立关闭的机关伞主题区域；视觉重心从“图”转为“机关伞 + 锁链 + 导电 + 墨雾”；不牺牲聊天正文和输入框。
